# Security Policy

## Supported Version

| Version | Supported |
|---------|-----------|
| 1.0.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public issue.
2. Email security details to the maintainers.
3. Include reproduction steps and impact assessment.
4. Allow reasonable time for a fix before public disclosure.

## Secret Exposure Response

If a secret is accidentally exposed:

1. Immediately rotate the compromised secret.
2. Revoke and regenerate all affected tokens.
3. Audit logs for unauthorized access.
4. Document the incident and remediation steps.

## Responsible Disclosure Process

- Acknowledge receipt within 48 hours.
- Provide a fix timeline within 7 days.
- Credit reporters (unless anonymity is preferred).

## Expected Response Process

- Triage and severity assessment within 24 hours.
- Hotfix for critical vulnerabilities within 48 hours.
- Coordinated disclosure after fix deployment.

## Do Not Publish

Do not publish sensitive vulnerability details in public issues or pull requests.
